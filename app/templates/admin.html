Web app service

Status: {{ service_raw }}


  
Start or stop from the device

  
Restart on this page brings the web app back by itself. Starting or stopping pecan-vision.service has to be done on the device. Stopping it takes this website offline, so this page cannot start it again afterward.

  
SSH into the kit, or VNC in and open a terminal, then run:

  
Stop the web app. The site stays down until you start the service again. Saved recordings stay on disk.

  
sudo systemctl stop pecan-vision.service

  
Start the web app. Wait a few seconds, then open http://<device-ip>:8080/admin. On the device itself, use http://localhost:8080/admin.

  
sudo systemctl start pecan-vision.service

  
See whether it is running with sudo systemctl status pecan-vision.service.
